# Next NBA session across days off

Quote discovery now crosses an empty today/tomorrow window using a bounded seven-calendar-day ESPN search. The scheduler preserves its normal two-date window when games exist, and otherwise selects the first future game date; it includes the following date only when evening fixtures can extend overnight. At most two calendar dates are returned for paid scans. Empty/intermediate dates only use free ESPN data. Malformed/unavailable calendars fail before slot reservation, preventing an outage from being interpreted as a rest day.

Home upcoming games can request the next nonempty publication session. Home and Pronostici use the same discovery for predictions while retaining the previous overnight session only if one of its games is still future. Publication dates remain the evening before overnight games: in the 3 November → early 5 November example, the preview belongs to the 4 November session, and its cutoff remains 4 November at 18:00 Europe/Rome. Early saved quotes cannot trigger publication at 18:00 on 3 November. The existing publication process still requires fresh pre-cutoff scans; no historical or official selections are rewritten and no model probabilities are changed.

Preview cards show the publication date and time; Top analysis headings identify preliminary selections. Quote-date discovery can reach the next playable date during longer gaps, and partial-scan fixture coverage is also preserved for future saved snapshots within the lookahead window.

Request controls: ESPN scoreboard responses have a shared bounded 60-second cache; failures are not cached. Provider fixture calendars retain their 48-hour positive cache, but empty lists expire after three hours so an early empty response cannot hide later availability for two days. This can add fixture-calendar calls while the provider has no events; tournament-odds requests retain existing shared slot caching and no single-game fallback is added. GitHub cron expressions now match the existing Render scheduler slots (09:00, 12:00, 14:30, 16:30, 17:30 Italy), using the same durable at-most-once slot claims.

Validation: 266 offline Python tests and 89 JavaScript/DOM tests pass locally, plus isolated tracking and grants/RLS integrations. New tests cover the November 3/5 gap, evening/overnight scan dates, paid-date bounds, long empty windows, provider/ESPN failure behavior, no early official publication, the actual 18:00 cutoff, frozen selections, calendar cache reuse, empty provider-cache rechecking, and dated preview labels. Syntax and diff checks pass. Runtime verification and deployment details are recorded in the pull request after publishing.

The change does not manufacture unavailable odds. New future quote rows appear only after a scheduled scan receives them from the provider; previews can change before the official cutoff.
